```
[청춘 일상 다이어트 총력전]

날짜별로  식단과  체중을  하나의  프로그램에서  관리하고  해당  내역을 
이용하여 계산된 수치를 토대로 자신의 식습관과 체중 변화를 쉽게 확인할 수 있는 프로그램

0. 사양
    - Python 3.14 이상 (Python 3.10에서도 동작하나, 본 프로그램은 Python 3.14를 토대로 만들어졌으므로 가급적 권장 버전을 사용할 것)
    - 왠만하면 VSCode환경에서 실행할 것

1. 실행 방법
    - 따로 라이브러리 다운 필요 없이 main.py를 VsCode에서 접속하여 실행 버튼을 누르기만 하면 된다

2. 주요 기능

    2.1 기능
    - 식단 기록 및 관리
        : 날짜를 선택하고 식사 시간대 별로 먹은 음식들을 추가한 후 해당 내역에 대한 CRUD를 수행한다
    - 체중 기록 및 변화 조회
        : 현재 날짜부터 최근 7일 간의 체중 기록을 조회하여 순서대로 출력하고, 가장 오래된 체중 기록과 현재 체중을 비교하여 체중의 변화를 수치로 환산하여 출력한다. 만약 현재 날짜의 기록이 없는경우 그 이전 기록을 기준으로 시작하여 만약 7일전의 기록이 없다면 그 후 날짜의 기록을 비교해 체중의 증감을 보여준다.
    - 일일 섭취 칼로리 계산
        : 현재 날짜를 기준으로 섭취한 음식의 칼로리를 모두 합하여 하루 총 섭취 칼로리를 출력한다.
    - 다이어트 총력전 리포트
        : 일일 섭취 칼로리와 목표 칼로리를 비교하여 목표 달성 여부를 판단하고 이를 출력한다. 위 필수 기능에 대한 화면 GUI를 구현함으로써 하루 동안의 식단 및 체중 관리 결과를 종합적으로 제공한다.
    - 음식 검색 기능
        : 식단 기록에서 음식을 추가할 때 검색하는 문자와 매칭되는 음식을 출력한다. 


    2.2 모듈
    - main.py : 주 실행 프로그램
    - gui_manager.py : Tkinter 모듈을 관리하기 위한 모듈로 GUI를 동적으로 관리 하기 위해 Window, Page, Widget 클래스를 만들어 사용자가 구조를 이해하기 쉽게 만들었다
    - operation_manager.py : gui_manager의 각 객체의 이벤트 혹은 동기화 함수에 필요한 값을 찾고 쓰거나 기능을 수행할 때 쓰이는 모듈이다
    - data_manager.py : operation_manager를 통한 데이터 저장 및 조회를 관리하는 모듈로 5분마다 백업 데이터를 저장하고 데이터를 안전하게 관리하게 해준다.

3. 파일 저장 구조
    - 숨김 폴더인 data에 저장되며 각각 records.json, foods.json을 통하여 데이터를 조회하고 저장한다.
    - 백업 폴더의 경우 data안에 backup이라는 이름으로 숨김 폴더로 저장되며 그 안의 시간대와 숨김 데이터 파일 2개가 존재한다 (records.json, foods.json)
    - 현재 데이터 로딩을 실패하는 경우 백업 데이터로 값을 가져와 반영한다.

4. 테스트 방법

    4.1 타입 오류
        : 입력 타입에 맞지 않는 값을 입력하였을 때 해당 예외를 처리할 수 있는가?
        ex/ 체중 입력, 칼로리 입력 칸에 문자를 삽입하는 경우 예외로 처리해서 안내 메시지를 발생시키는가?

        성공 조건 : 프로그램이 비정상 종료되지 않는가?


    4.2 디바운스
        : 이벤트 처리 중 버튼 이벤트가 한번 더 발생할 때 오류를 발생하지 않게 할 수 있는가? 
        ex/ 오토 마우스를 사용하여 버튼을 엄청난 횟수로 연속 클릭

        성공 조건 : 프로그램이 비정상 종료되지 않는가?
```
